# Medical Management App

A simple full-stack web application built with Spring Boot and Angular.

This project demonstrates a modern web application architecture with a Java Spring Boot backend and an Angular frontend. It includes REST API communication, database integration, authentication using JWT tokens, and role-based access control.

## Features

- REST API for backend communication
- JWT-based authentication
- Role-based access control
- CRUD operations
- Database persistence with JPA/Hibernate
- Client-side routing
- Dynamic user interface
